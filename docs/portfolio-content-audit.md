## 仍需人工及正式環境驗證

1. **作者與案例權限**：網站上的品牌、照片、作品與服務敘述是否已有公開授權；應由權利人確認。
2. **內容來源**：其他文章仍可能存在未附引文的非量化敘事、年份或第一人稱經歷；本次不視為逐句核實完成。
3. **發表日期與更新日期**：舊文章 frontmatter / excerpts 不代表實際發布，禁止使用這些日期生成未驗證的已發布網址。
4. **資料庫不受本 PR 影響**：如果 Manus 的資料庫早已匯入舊文章，修改 GitHub 靜態文章草稿不會自動覆蓋、下架或更正既有 DB 記錄。需要先唯讀匯出已發布清單與來源，再提出最小更新。
5. **SEO 與 Sitemap**：動態 XML 僅使用 production Express 的 `blog_posts.is_published = true` 查詢。Manus 是否真的執行這條路徑，需要部署後從 HTTP 回應驗證。
